Clientes

Esta es la ventana de mantenimiento de clientes del módulo de Bancos. Aquí puede consultar, agregar, modificar y eliminar los clientes registrados. De cada cliente se guarda su número, nombre, dirección, teléfono y estado.




¿Cómo abrir la ventana de Clientes?

1. En la barra superior del módulo de Bancos presione el menú "Catálogos".

2. Elija la opción "Clientes". Se abrirá la ventana "8014 – Clientes".




Conozca la ventana

1. Barra de botones: contiene todas las acciones que puede realizar con los clientes.

2. Formulario: aparece al presionar "Ingresar" o "Modificar" y es donde se escriben los datos del cliente.

3. Tabla de clientes: muestra un cliente por fila. La fila en azul es el cliente seleccionado.

La tabla tiene estas columnas: "pk_idCliente" es el número del cliente; "nombreCliente" es su nombre; "direccionCliente" y "telefonoCliente" son su dirección y teléfono; "estadoCliente" indica si el cliente está activo (1) o inactivo (0).




Los botones de la barra

1. Ingresar; permite escribir un cliente nuevo.

2. Consultar; busca un cliente en la tabla.

3. Modificar; permite cambiar los datos del cliente seleccionado.

4. Eliminar; borra el cliente seleccionado.

5. Guardar; confirma lo que escribió al ingresar o modificar.

6. Cancelar; deja lo que estaba haciendo sin guardar cambios.

7. Refrescar; vuelve a cargar la tabla con los datos más recientes.

8. Imprimir; abre el reporte de clientes.

9. Ayuda; abre este archivo de ayuda.

10. Inicio; se posiciona en el primer cliente de la tabla.

11. Anterior; retrocede un cliente.

12. Siguiente; avanza un cliente.

13. Fin; se posiciona en el último cliente de la tabla.

14. Salir; cierra la ventana.




Ingresar

Use este botón para registrar un cliente nuevo. Siga estos pasos:

1. Presione el botón "Ingresar"; se abre el formulario "Nuevo registro".

2. pk_idCliente; escriba el número del cliente. Este número lo escribe usted y no puede repetirse.

3. nombreCliente; escriba el nombre del cliente.

4. direccionCliente y telefonoCliente; escriba la dirección y el teléfono.

5. estadoCliente; escriba 1 si el cliente está activo o 0 si está inactivo. Si no ve este campo, baje con la rueda del mouse dentro del formulario.




Guardar

Después de presionar "Ingresar" (o "Modificar") y llenar los datos, siga estos pasos:

1. Presione el botón "Guardar".

2. Aparece un mensaje que confirma que el registro quedó guardado. Presione "Aceptar".

3. La tabla se actualiza y muestra el cliente guardado.




Consultar

1. Presione el botón "Consultar". Se abre una ventana para elegir el cliente que desea buscar; selecciónelo y acepte. La tabla muestra solo ese cliente. Para volver a ver todos presione "Refrescar".




Modificar

1. Seleccione en la tabla el cliente que desea cambiar y presione el botón "Modificar". Sus datos aparecen en el formulario; el número (pk_idCliente) no se puede cambiar.

2. Cambie lo que necesite y presione "Guardar". La tabla se actualiza con los nuevos datos.




Eliminar

1. Seleccione en la tabla el cliente que desea eliminar y presione el botón "Eliminar".

2. El sistema le pide confirmar. Si acepta, el cliente se elimina y la tabla se actualiza sin él.

Si solo quiere que un cliente deje de usarse, puede usar "Modificar" y cambiar su estado a 0 en lugar de eliminarlo.




Cancelar

Si está ingresando o modificando un cliente y ya no desea continuar, presione "Cancelar". El formulario se cierra y no se guarda ningún cambio. Este botón no elimina clientes.




Reporte

1. Presione el botón "Imprimir". Se abre el reporte con el listado de clientes: número, nombre, dirección, teléfono y estado.

2. Desde la barra del reporte puede cambiar de página y exportarlo.
